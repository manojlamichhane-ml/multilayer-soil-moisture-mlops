Root-zone soil moisture, layer by layer

Satellites see the top few centimetres of soil. This model reaches 180 cm: it predicts the 30 cm layer from PlanetScope imagery, weather and soil data, then passes each answer down to the layer below.

    One model per depth, chained top to bottom

    Four data sources are joined at each access tube, cleaned, and reduced to the most informative inputs for each depth with SHAP. An XGBoost model then predicts 30 cm. That prediction becomes an extra input for the 60 cm model, its answer feeds 90 cm, and so on down to 180 cm.

    Data fusionPlanetScope bands and indices at 3 m, daily weather with antecedent rain, lab soil texture, organic matter and pH in five layers, and elevation.
    Feature selectionFor each depth, inputs are ranked by SHAP and added one by one until the test score stops improving: 5 to 11 inputs per depth.
    Chained predictionThe predicted moisture of the layer directly above is added as an input. Near the surface the sky drives moisture; deeper down, the layer above and the soil itself take over.

    What the chain buys you

    Scores on observations the models never saw. During training, the layer-above input is an out-of-fold prediction, so the chain is judged exactly as it will run on new data.
